# Database Concepts

Runnable demos of database and SQL concepts, each with tests that prove the behavior.

| Topic | What it shows |
|---|---|
| [n-plus-one](n-plus-one/) | The N+1 query problem and two fixes (JOIN, batch IN), with query-count tests |

Run any demo: `python <folder>/<file>.py` (Python 3, SQLite built in, no installs).
